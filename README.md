# ひと目トーク

耳が聞こえる人と聞こえない人が、ボタンと大きな文字で素早く意思疎通するための PWA です。

- 入力内容・操作履歴は保存も送信もしません（画面を閉じると消えます）。
- 初回表示のあとはオフライン（機内モード）でも起動します。Google フォントが読めないときは端末の日本語フォントで表示します。
- 画面の向きは固定しません。

公開 URL: https://hitome-talk.vercel.app

## 使い方

### 画面の見かた

- **大きな表示（カード）** … ボタンを押した言葉が、画面いっぱいに大きく出ます。相手に画面を見せて伝えます。カードの左上に「だれからの言葉か」が出ます。
- **ボタン側** … 上の 3 つで「だれが伝えるか」を選び、その下の一覧から言葉を選びます。
- 縦長の画面では、上が大きな表示・下がボタンです。横長の画面では、左が大きな表示・右がボタンです。

### 基本の流れ

1. 上の 3 つのボタンから、伝える人を選びます。選んでいる役割には「✓」が付きます。
   - **聞こえる人**（青・丸）
   - **聞こえない人**（橙・ひし形）
   - **どちらでも**（灰青・四角）
2. 一覧から言葉のボタンを押すと、大きく表示されます。
3. 言葉を表示すると、一覧の先頭に **「返事の候補」** が出ます。相手が返しそうな言葉が並び、役割も自動で相手側に切り替わります。相手が押すか、続けて別の言葉を選んでください。
4. 色だけでなく、ラベル・形・「✓」でも役割を区別できます。

### 方向で案内する

「聞こえる人」と「どちらでも」の一覧にある **方向で案内する** で、道順を矢印つきで伝えられます。

1. 案内するもの（出口・階段・係員・安全な場所・避難所）を選びます。
2. 方向（左・まっすぐ・うしろ・右）を押すと、「出口は 右です」のように、大きな矢印つきで表示されます。

### 文字を入力して表示する

定型文にない言葉は、ボタン側の一番下の **文字を入力して表示** から入力できます（100 文字まで）。選んでいる役割の言葉として、大きく表示されます。

### やり直し

- **ひとつ戻す** … 直前の表示を取り消します。
- **全部消す** … これまでの表示をすべて消して、最初の画面に戻します。

### そのほか

- 画面を操作しているあいだは、画面が消えないようにします（対応している端末のみ）。
- 直前までのやりとりは、カードの上部に小さく並びます（直近 2 件）。
- 端末の設定に合わせて、明るい配色と暗い配色が切り替わります。
- 画面が狭いときは、上部の見出しやボタンを縮めて 1 行に収めます。Chrome の「ページのズーム」を大きくしているときも、同様です。

### このアプリについて（隠し機能）

画面左上のロゴ「ひと目トーク」を、**1.5 秒以内に 3 回続けて押す**と、「このアプリについて」の窓が開きます。災害時など、画面を見たいときに余計な情報が出ないよう、普段は隠しています。

- **更新のお知らせ** … 直した内容の履歴（`changelog.html`）を、別のタブで開きます。
- **ご意見・ふぐあいを送る** … ご意見フォームを、別のタブで開きます。アプリの表示内容は送られません。
- 「とじる」で、元の画面にそのまま戻ります（表示中の言葉は消えません）。
- キーボードや読み上げで操作するときは、ロゴを選んで 1 回押せば開きます。

### ホーム画面に追加する（Android・Chrome）

1. Chrome で公開 URL を開き、画面が出るまで数秒待ちます。
2. 右上の「⋮」メニューから「ホーム画面に追加」を選び、「インストール」を押します。
3. ホーム画面のアイコンから起動します。一度開いたあとは、機内モードでも使えます。

新しい版が出たときは、アプリを開くだけで更新されます。更新が反映されないときは、アプリを完全に閉じて、もう一度開いてください。

## ファイル

- `index.html` … 本体（HTML・CSS・JS）
- `changelog.html` … 更新のお知らせ（改修したら、ここに書き足す）
- `manifest.webmanifest` / `icon.svg` / `icon-192.png` / `icon-512.png` … PWA 設定とアイコン
- `sw.js` … オフライン用の service worker（更新したら `CACHE` のバージョンを上げる）
- `docs/LESSONS.md` … 過去の失敗と教訓

ビルド不要の静的サイトです。Vercel に配置しています。
